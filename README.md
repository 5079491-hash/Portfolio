# Personal Portfolio Website

## About the Project

This is my personal portfolio website developed as part of my Web Development Internship. The portfolio is designed to provide a professional online presence and showcase my educational background, technical skills, projects, certifications, resume, and contact information.

The website is developed using HTML, CSS, and JavaScript. It has a simple, clean, user-friendly, and responsive design that can be accessed from different devices.

## Objectives

The main objectives of this project are:

- To develop a professional personal portfolio website.
- To showcase my technical skills and knowledge.
- To present my academic background and career interests.
- To display my projects and practical work.
- To showcase my certifications and achievements.
- To provide access to my resume.
- To provide contact and social media information.
- To gain practical experience in front-end web development.
- To learn how to manage and deploy a website using GitHub.

## Features

The portfolio website includes the following features:

- Personal introduction
- About Me section
- Technical Skills section
- Projects section
- Certifications section
- Resume section
- Contact section
- GitHub profile link
- Responsive website layout
- Interactive elements using JavaScript
- Resume viewing and downloading
- Online website deployment using GitHub Pages

- Page layout

- Responsive design
- Hover effects

### JavaScript

JavaScript is used to add interactive functionality to the website. It helps make the website more dynamic and user-friendly.
How to Run the Project Locally
The project can also be run locally using Visual Studio Code.
Download or clone this repository.
Open the project folder in Visual Studio Code.
Make sure all HTML, CSS, JavaScript, image, and resume files are in their correct folders.
Open index.html.
Install the Live Server extension in Visual Studio Code if it is not already installed.
Right-click on index.html.
Select Open with Live Server.
The portfolio will open automatically in the default web browser.
